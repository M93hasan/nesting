# README medya dosyaları

Ana depo README dosyasındaki görsel ve video alanları için dosyaları bu klasöre ekleyin:

- `re.png` — uygulamanın ekran görüntüsü.
- `ve.mp4` — uygulama tanıtım videosu.

Bu iki dosya henüz eklenmediğinde ana README içindeki bağlantılar çalışmaz. Dosya adlarını ve uzantılarını aynen koruyun. Büyük videoları Git deposuna koymak yerine GitHub Releases veya YouTube üzerinden barındırıp README'den bağlantı vermek daha uygun olabilir.
